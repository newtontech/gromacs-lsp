# Changelog

All notable changes to gromacs-lsp will be documented in this file.

## [0.0.3] - 2026-06-15

### Added

- Release metadata for OpenQC provenance gates, including `VERSION`,
  `CHANGELOG.md`, and manifest pointers.
- Extended runtime diagnostics and repair preview support for GROMACS inputs and
  logs.

## [0.0.2] - 2026-03-04

### Changed

- Bumped the package version for the upstream parser baseline.

## [0.0.1] - 2026-03-04

### Added

- Initial GROMACS LSP scaffold and MDParser-based topology parser foundation.
